## 🎯 项目简介

这是一个基于 VitePress 构建的 AI 教程网站，提供：

- 📚 系统的 AI 知识体系
- 💻 丰富的代码示例
- 🚀 实战项目指导
- 🔍 搜索功能支持

**网站地址**: https://creb.ai

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 本地开发

```bash
npm run docs:dev
```

访问 http://localhost:5173

### 构建部署

```bash
npm run docs:build
```

### 预览构建结果

```bash
npm run docs:preview
```

## 🛠️ 技术栈

- [VitePress](https://vitepress.dev/) - 静态网站生成器
