#### 代码示例：调用OpenAI API

```python
from openai import OpenAI

# 初始化客户端，API Key从环境变量读取
client = OpenAI(api_key="您的API_KEY")

# 发起聊天请求
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "请用Python写一个快速排序函数。"}]
)

# 打印结果
print(response.choices[0].message.content)
```

### 2.2 快速部署工具（告别复杂配置）

#### 方案一：Ollama（最强推荐，全平台支持）

Ollama 让本地运行大模型变得像使用 Docker 一样简单。

```bash
# 1. 安装Ollama (https://ollama.com/)
# 2. 拉取模型（以Qwen2.5-7B为例）
ollama pull qwen2.5:7b

# 3. 运行并与模型交互
ollama run qwen2.5:7b

# 4. 启用API服务（默认端口11434）
ollama serve
```

**通过API调用本地模型**：
```python
import requests

url = 'http://localhost:11434/api/generate'
data = {
    "model": "qwen2.5:7b",
    "prompt": "为什么天空是蓝色的？"
}

response = requests.post(url, json=data)
print(response.json()['response'])
```
